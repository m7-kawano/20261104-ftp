# 星屑ドッジ — STARDUST DODGE

ブラウザで遊べる弾幕系シューティング（回避型サバイバル）ゲームです。
ビルドや依存パッケージは不要です。`index.html` をブラウザで開けば遊べます。

## 遊び方

| 操作 | キー |
| --- | --- |
| 移動 | 十字キー / WASD |
| 低速移動（当たり判定とグレイズ範囲を表示） | Shift |
| 決定 | Enter / Space / Z |
| 戻る | Esc / X |
| 一時停止 / 再開 | Esc / P |
| すぐにリトライ（リザルト画面） | R |
| 消音の切り替え | M |

画面をドラッグして自機を動かすこともできます。

1. タイトル画面で Enter（またはクリック）
2. 「簡単」「普通」「難しい」から難易度を選ぶ
3. 3・2・1 のカウントダウン後に弾幕が始まる。時間が経つほど弾幕が激しくなる
4. ライフがなくなるとゲーム終了。リザルト画面にスコア、生存時間、グレイズ数、ランクを表示する

## 難易度

| 難易度 | ライフ | 弾速・密度 | スコア倍率 |
| --- | --- | --- | --- |
| 簡単 | 3 | 低い | ×1 |
| 普通 | 2 | 標準 | ×2 |
| 難しい | 1 | 高い | ×4 |

## スコア

- **生存ボーナス**：毎秒 `100 × 難易度倍率 × (1 + 経過秒数 / 60)` が加算されます。長く生き延びるほど、1秒あたりの加点も増えます。
- **グレイズボーナス**：弾をかすめる（グレイズする）たびに `10 × 難易度倍率` が加算されます。
- ベストスコアは難易度ごとにブラウザ（localStorage）に保存されます。
- ランクは生存時間で決まります（S: 150秒以上 / A: 90秒以上 / B: 50秒以上 / C: 25秒以上 / D）。

## 画面遷移

すべての画面（タイトル → 難易度選択 → カウントダウン → プレイ → 一時停止 → リザルト）は、
フェード・ブラー・スケールと時間差のアニメーションでつながっています。
画面を切り替えるときは、弾が光の粒になって消えます。背景の色も、選んだ難易度の色へ少しずつ変わります。
被弾してゲームが終わるときは、スローモーションと閃光が入ってからリザルト画面に切り替わります。

## ファイル構成

- `index.html` — 画面（UI）の構造
- `style.css` — 見た目と画面遷移のアニメーション
- `game.js` — ゲームロジック、弾幕パターン、描画、入力処理
